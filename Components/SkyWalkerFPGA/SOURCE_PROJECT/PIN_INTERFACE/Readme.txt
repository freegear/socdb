FPGA to FPGA pin interface
: FPGA와 FPGA간에 핀 컨넥션 테스트로서 각각의 FPGA에 shift-register를 넣어 두개의 데이터를 비교하여 같으면 다음 핀 확인으로 넘어가는 방식으로 되어져 있습니다.
  각각의 핀간에 short 또는 단선된 경우 다른 데이터가가 나와 error mode로 전환하여 어떤 핀과 이상이 있는지를 판단하게 됩니다.  
  단, 이 테스트에서는 기본동작 클럭이 25[MHz]로서 보다 높을 주파수를 사용할 경우에는 delay에 의한 오류가 나올 수도 있습니다.
  현재 체크하고 있는 핀을 알아보기 위해 내부의 state-machine에 delay을 준 것으로서 동작 시퀀스와는 무관하게 동작하므로 공급클럭 주파수를 높이는 것은 오동작을
  발생시킬수도 있습니다.   * test시 33[MHz]에서 오류 발생 p.13x대에서 발생했음.*
