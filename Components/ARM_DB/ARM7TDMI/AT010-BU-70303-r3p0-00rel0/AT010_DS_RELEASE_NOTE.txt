| SECTION B - DELIVERABLES SUMMARY                                        |
+-------------------------------------------------------------------------+
Description of deliverables included in this release.

This is a 'Bundle' release, part number 'AT010-BU-70303-r3p0-00rel0' which
requires no unpack or similar installation script.  After unpacking the
supplied .tgz file you will find that licenced deliverables are arranged
in the working directory structure. 

This release is intended to be a replacement for all previous releases.
You should not attempt to mix any files from this release with any
previously released files.  Please do not unpack this release over an
older release as some files in the old release will be write protected.
Unpack the release into a clean empty environment.

The 'Bundle' release 'AT010-BU-70303-r3p0-00rel0.tgz' contains the
following constituent parts:

DOCUMENTS
---------
AT010-DC-70318-r3p0-00rel0   Trial Design Kit Release Note - ASCII format
AT010-DA-03001-3A.00	     ARM7TDMI Technical Reference Manual (TRM)
AT010-DC-11001-3A.02         ARM7TDMI Core Errata List
AT010-DC-13001-3A.1.1        ARM7TDMI Integration Manual
AT010-DC-06041-3A.00         ARM7TDMI DesignStart Kit User Guide

AMBA Design Data
----------------
AT010-MN-22001-3A.00         ARM7TDMI AHB Wrapper - Verilog RTL
AT010-MN-01001-3A.00         ARM7TDMI AHB Wrapper - Synopsys synthesis scripts
AT010-MN-22003-3A.00         AMBA/JTAG Simulation Environments - Verilog RTL

Test Vectors
------------
AT010-VE-01309-3A.00         ARM7TDMI JTAG Production Vectors subset
AT010-VE-01303-3A.00         ARM7TDMI AMBA Production Vectors subset

The following contracted parts are NOT included in this bundle:

FOUNDRY SPECIFIC KIT
--------------------

LFxxx-BU-70303 (where 'xxx' is a variable number)

This is another bundle release that is downloaded separately. This
bundle is process-specific and the contents will vary for each
foundry/process combination.

It is strongly recommended that the LFxxx-BU-70303 bundle is unpacked 
under the same directory as AT010-BU-70303-r3p0-00rel0 since both
bundles share common directory structure.

MODELS
------

AT010-MS-XXYYY Design Simulation Models (DSM)

These are simulator/platform specific and need to be downloaded separately.
