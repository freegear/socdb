| SECTION B - DELIVERABLES SUMMARY                                        |
+-------------------------------------------------------------------------+
Description of deliverables included in this release.

This is a 'Bundle' release, part number 'LF054-BU-70303-r3p0-00rel0' which
requires no unpack or similar installation script.  After unpacking the
supplied .tgz file you will find that licenced deliverables are arranged
in the working directory structure. 

This release is intended to be a replacement for all previous releases.
You should not attempt to mix any files from this release with any
previously released files.  Please do not unpack this release over an
older release as some files in the old release will be write protected.
Unpack the release into a clean empty environment.

The 'Bundle' release 'LF054-BU-70303-r3p0-00rel0.tgz' contains the
following constituent parts:

DOCUMENTS
---------
LF054-DC-70318-r3p0-00rel0   DesignStart Kit Release Note - ASCII format
AT010-LA-37105-3A.06         Performance Summary (Area, Power, Speed)

EDA Tool Layout Data
--------------------
AT010-LA-05105-3A.06   PFC Timing file. 
AT010-LA-23105-3A.06   Timing view in Synopsys .LIB  format
AT010-LA-35105-3A.10   Footprint view in Cadence .LEF format
AT010-LA-36105-3A.09   Footprint view in Synopsys .FRAM format
AT010-LA-41105-3A.06   Timing view in Synopsys .CLF format


The following contracted parts are NOT included in this bundle.

ARM7TDMI Integration Kit
------------------------

AT010-BU-70303

This is another bundle release that is downloaded separately. This
bundle contains generic data common to all foundry-specific
DesignStart kits.

It is strongly recommended that the AT010-BU-70303 bundle is unpacked 
under the same directory as LF054-BU-70303-r3p0-00rel0 since both
bundles share common directory structure.


MODELS
------

AT010-MS-XXYYY Design Simulation Models (DSM)

These are simulator/platform specific and will be provided in a separate
release as individual parts.
