netlist simulations can be ignored:

../uut/<netlist file name>.sdf21  LXXXXX: SDFA Error: Unable to find source port tbench.uut.<port name>

../uut/Mpmc_scanready_verilog.sdf21  LXXXXXX: SDFA Warning: Negative
timing check limit -X.XXXXX set to 0
