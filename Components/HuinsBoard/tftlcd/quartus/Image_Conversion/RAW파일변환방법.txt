320 * 240 을 RAW 파일로 변환시키는 방법

 : 먼저..그림 파일은 BMP로 되어 있어야 된다..BMP FILE NAME = AAA (AAA.BMP)라 가정하고

1)BMP2RAW파일을 실행시킨다

   > BMP2RAW  AAA                (<--<-- AAA 는 FILE NAME)

   
   ---------그럼 AAA.R24파일이 생성된다---------------

2) 그리고 CON16을 시킨다.. 이것은 데이타 포멧을 16비트로 변환시켜주는 것으로

   > CON16 AAA                   (<-- AAA 는 FILE NAME)

  ----------그럼 AAA.R16파일이 생성된다------------------
   이것이 16bit RAW 파일이된다..

3)  이것의 파일 이름을  AAA.R16 ---> pic.raw로 변환시키고
  

4) raw2hex.exe파일을 실행시킨다
 
   -----------그럼 hex.h가 생성된다..--------------------


   이것을 쓰면된당...ㅋㅋㅋㅋ수고하셨습니다...
