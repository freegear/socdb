 arm-gcc-2.95.3.tar.bz2
--------------------------------------------------------
decompressing cross-2.95.3.tar.bz2

>> tar jxf cross-2.95.3.tar.bz2
>> ls
  2.95.3

you can show the directory named 2.95.3


and then.. make "arm" directory in /usr/local
>> mkdir /usr/local/arm


move 2.95.3 to /usr/local/arm/
>> mv 2.95.3 /usr/local/arm


Add the path "/usr/local/arm/2.95.3/bin/" into /root/.bash_profile file
>> vi /root/.base_profile

PATH=$PATH:/usr/local/arm/2.95.3/bin/


finally, execute the command following...
>> source /root/.bash_profile
