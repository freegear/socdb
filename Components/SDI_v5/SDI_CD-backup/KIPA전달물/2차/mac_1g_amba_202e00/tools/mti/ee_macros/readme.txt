Please follow the steps to execute macros for Model Telchnology Inc.
from within ModelSim EE simulator:

1. Run MTI simulator (vsim),

2. Change Directory to your work directory (menu File/Change Directory),
   for example: 
		/MAC_1G_AMBA
   
3. Enter command to execute compilation macro:
   		do tools/mti/ee_macros/compile.do

4. Enter command to execute simulation macro:
   		do tools/mti/ee_macros/simulation.do

5. Enter command to start simulation, 
   for example:   		
		run 100 us
