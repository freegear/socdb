Jtagger Commands

Jtagger is controlled via the command line interface, although the commands are quite simple they can do most of what you need to get a CPU up and running. They can also be chained together into a script.

Please note that all numerical values are entered in hex (ca132 for example).

Normal Commands

JTAG

Resets the JTAG interface

IDENT

Returns the Chip ID

REGS

Dumps the contents of the registers to screen

Debug Commands

STATUS

Displays current debug status

HALT

Halts the processor and reports current PC

RESTART

Restarts processor from where it was stopped

RUN address

Restarts processor from specified 'address'

PEEK address

reads the long word at location 'address'

POKE address data

sets the long word at 'address' to 'data'

File Commands

LOAD file [address [length] ]

Loads the binary file into memory starting at 'address' upto maximal 'lenght'

DUMP file address length

Dumps the contents of memory from 'address' of 'length' to 'file'

SCRIPT file

Reads a sequence of commands from 'file'. halts on first error
