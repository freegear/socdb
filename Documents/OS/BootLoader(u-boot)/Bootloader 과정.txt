II.[ Porting Point ]
	1. When just board level is. (CPU is already ported. ex s3c44b0x)
	- Add a new configuration option for your board to the toplevel "Makefile"
	- Create a new directory to hold your board specific code.
	  you will need at least the "Makefile", a "<board>.c", "flash.c" and "u-boot.lds".
	- Create a new configuration file "include/configs/<board>.h" for your board

    
    Makefile
	board/target_board
	include
		/configs/target.h

	2. When new cpu type is.
	- Create a new directory to hold your CPU specific code.
	- Add any files you need.

    Makefile
	board/target_board
	cpu/target_cpu
	lib_target/
	include
		/asm-target/
		/configs/target.h
	etc.. Needs to H/W dependent file porting


######
III.[ Building ]
	1. Run "make <board>_config" with your new name.
	2. Type "make"

IV.[ Bootloader 과정 function call hierarchy ]

1. Startup code
: Bootloader copy flash to ram area and
	real bootloader function call

	WDT / interrupt disable
	clk control
	
	cpu_init_crit()	: SRAM initialize
	boot code copy flassh to ram area
	stack setup
	clear bss section
	
	start_armboot() call

2. C-routine
	start_armboot()
		// Environment setting & board initialize
		cpu_init()			:	cpu/xxx/cpu.c
			- basic cpu dependent setup (#ifdef STACKDEFINE 스택 start 설정)
		board_init()		:	board/xxx/xxx.c
			- basic board dependent setup
			* pll setting
			* gpio setting
			* arch number & boot parameter setting
			* i/d cache enable
		interrupt_init()	: cpu/xxx/interrupts.c
			- interrupt setting
		env_init()			: tools/env/fw_env.c
			- initialize environment
			- 설정에 따라서 호출 함수(파일) 달라짐
		init_bardrate()		: lib_arm/board.c
			- initialize baudrate setting
		serial_init()		: cpu/armxxx/xxx/serial.c
			- serial comm setup
		console_init_f()	: common/console.c
			- stage 1 init of console
		display_banner()	: lib_arm/board.c
		dram_init()			: board/xxx/xxx.c
			- configure available RAM banks
		display_dram_config(): lib_arm/board.c


		flash_init()		: board/xxx/flash.c
			- flash setting
		env_relocate()		: common/env_common.c
			- default_environment[] copy to env area
		ipaddr / mac address board specific structure에 저장
		devices_init()		: common/devices.c
			-
		jumptable_init()	: lib_arm/board.c
		console_init_r()	: common/console.c
			- device out/in/err device & function setting
		enable_interrupts()	: cpu/armxxx/interrupts.c


		// Kernel download & booting
		main_loop()			: common/main.c
			readline()		: common/main.c
				- read command from console

			run_command()	: common/main.c
				- run command (bootm or tftp)

				do_tftpb()	: common/cmd_net.c
					netboot_common()				
				do_bootm()	: common/cmd_bootm.c
					- memmove() : image header read
					do_bootm_linux()	: lib_arm/armlinux.c
						- parameter store
						- theKernel() -> kernel start
