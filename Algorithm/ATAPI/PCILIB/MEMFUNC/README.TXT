ハイメモリアクセスライブラリ(MEMFUNC)  Ver.2.0  for PC/AT


　Interface1999年3月号の第5章に掲載時より新たな関数が追加されバージョンアップが行われています．最新版の関数一覧は本アーカイブファイル同封の MEMFUNC.TXT を参照してください．
　さらに対応コンパイラとして，LSI C-86試食版以外にTurbo Cにも対応しました．

●MEMFUNCについて
　アセンブルにはTurboアセンブラ 2.01を使用しています．


●MEMTESTのコンパイル方法
▲MEMTESTL.EXE(LSI C-86試食版)
　MEMTESTL.EXEはLSI C-86試食版でコンパイルしたEXEファイルです．LSI C-86試食版をコンパイルできる環境下で，カレントディレクトリに MEMTEST.C MEMFUNC.H MEMFUNC.OBJ MKSMP.BAT を置いて，そこで MKSMP.BAT を実行するとコンパイルされます．

▲MEMTESTT.EXE(Turbo C)
　MEMTESTTはTurbo C 2.0でコンパイルしたEXEファイルです．Turbo Cをコンパイルできる環境下で，カレントディレクトリに MEMTEST.C MEMFUNC.H MEMFUNC.OBJ MEMFUNC2.OBJ MKSMP.BAT を置いて，そこで MKSMP.BAT を実行するとコンパイルされます．


●MEMTESTの動作内容
　このプログラムで16Mバイト以降のメモリアドレスを使用しているので，20Mバイト程度のメインメモリを搭載したシステムでないと動作しません．
　まず新しく追加されたgetCpuMode()関数を使ってCPUモードをチェックし，EMM386などのメモリドライバが動いていないかどうか確認します．以降のメモリ読み書きでアドレス1Mバイト以降の領域を使うため，EMM386などのメモリドライバが動作しているとドライバ領域を破壊してしまうためです．
　まずアドレス16Mバイト(1000000h～)のところに，バイト/ワード/ダブルワードの各サイズで任意のデータを書き込み読み出して結果を表示します．
　また配列変数に値をセットし，その配列の内容をアドレス1100000hの領域に書き込みます．そして別の配列にアドレス1100000hの領域を読み出して，ダンプ表示します．
　さらに新しく追加されたハイメモリ間ブロック転送関数を使って，アドレス1100000hの領域をアドレス1200000hの領域に直接コピーします．そして配列に読み出して先頭16バイトをダンプ表示します．
　またアドレス1300000のところにダブルワードで値を書き込み，64ワード(256バイト)メモリフィルをします．これも同様に配列に読み出して先頭16バイトをダンプ表示します．


　なお，日本語ドライバ(DOS/Vシステム)もハイメモリ領域を使用しているので，このプログラムではアドレス16Mバイト以降の領域を使用しました．こちらのテストでは日本語ドライバが動作している環境でも動いていますが，使用する日本語ドライバのバージョンによってはハイメモリ領域の使い方が異なる場合もあります．この関数群でハイメモリ領域を直接操作される場合は，メモリドライバはもちろん，日本語ドライバも常駐させない環境で使用するのが安全だと思われます．
