■概要

  ﾒﾓﾘ4Gﾊﾞｲﾄとﾌｧｲﾙの任意のアドレスのダンプ&エディット
  VCPIおよびDPMI対応で、Windows3.1およびWindows95のDOS窓環境でも動作可能

■動作環境

  ・MS-DOS or PC-DOS 環境
  ・Windows3.1 or Windows95 DOS窓

  NTのDOS窓では動きません。またPC-98シリーズでも動きません。


■使用方法

    [Address]  ﾀﾞﾝﾌﾟ&ｴﾃﾞｨｯﾄを開始するｱﾄﾞﾚｽ

               例｡
                    DEHEHE.BIN を編集したい場合

                      MEMORY @DEHEHE.BIN

                    とする
