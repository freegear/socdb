Hybrid's OpenVG Reference Implementation 1.0

Release notes

Released: Thursday, 20 October 2005.

This is the Reference Implementation (RI) of the OpenVG 1.0 specification. This package contains the binary-only OpenVG DLL and a sample project. The RI is currently only available for Windows. If there is sufficient interest in versions for other desktop OSes (Mac OS X, Linux), they may be made available as well. No mobile device version will be provided.

The production-ready OpenVG 1.0 Performance Implementation (PI) is available elsewhere on the Hybrid website.

The purpose of the RI is to act as a reference against which high-speed implementations can be tested, and therefore it utilizes the highest-quality algorithms for all of its rendering. This means that the performance of the Reference Impelementation does not reflect the performance of OpenVG implementations: even software-based implementations optimized for speed run two or three orders of magnitude faster.

If you wish to join in on the testing, send your bug reports to Hybrid's bug database with the Reporting bugs Web form.
You may also post your bug reports or join in on the discussion at the Hybrid Graphics Forums

Hybrid's OpenVG 1.0 Reference Implementation requires that the OpenGL Utility Toolkit (GLUT) library is installed. The toolkit and further information is freely available at the OpenGL Coding Resources Web site. For direct download, go to the GLUT for Win32 page.
